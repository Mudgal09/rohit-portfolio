Rohit Power Tools
eCommerce Platform

A production-grade, AI-powered full-stack eCommerce platform for selling professional power tools across India — with live Razorpay payments, an intelligent chatbot, and a complete admin system.

⚡ Featured Project 🤖 AI Powered 💳 Razorpay Live 2025 – Present
Project Overview
What is this project?

Rohit Power Tools is a real-world, production-grade eCommerce web application built entirely from scratch using the MERN-adjacent stack. It's designed to replicate the experience of a real online store — not a tutorial project, but something that could actually be deployed and used by a business.

The platform handles the complete shopping lifecycle: product discovery, cart management, secure checkout with Razorpay (supporting UPI, credit/debit cards, and Cash on Delivery), order tracking with a visual timeline, and post-purchase management. On the backend, a full admin dashboard allows real-time management of products, orders, and users.

The standout feature is Bolt — an AI customer support chatbot powered by Google Gemini 2.5 Flash — integrated directly into the storefront to handle common queries, product questions, and order status checks.

Engineering Challenges
Problems I solved
1
Razorpay Payment Verification
Ensuring payment integrity required implementing server-side HMAC-SHA256 signature verification. Client-side confirmation alone isn't sufficient — the backend validates every payment before marking orders as paid, preventing spoofed confirmation requests.
2
AI Chatbot Context Management
Integrating Gemini 2.5 Flash required careful prompt engineering to keep the chatbot scoped to store-related topics while maintaining natural conversation flow. I built a context injection system that feeds relevant product data to the model for accurate responses.
3
Concurrent Cart State Management
Managing cart state across sessions while handling stock changes (products going out of stock while in cart) required careful conflict resolution logic — cart items are validated against live inventory on every checkout attempt.
4
Image Optimisation Pipeline
Building a Multer → Cloudinary pipeline that handles multiple image formats, auto-generates thumbnails at different sizes, and serves optimised WebP versions via CDN required careful middleware chaining and error handling for upload failures.
