Project Overview
What is MYSW-Camp?

MYSW-Camp (Make You See Wonders) is a full-stack campground review platform inspired by YelpCamp — a classic web development project taken to production quality. Users can discover campgrounds on an interactive map, share their own experiences, write reviews with star ratings, and upload photos.

The project focuses on real-world web development patterns: MVC architecture with Express.js, database relationships with Mongoose, secure user authentication via Passport.js, and seamless media handling with Cloudinary. It's currently live and deployed on Render.com.

Every detail has been considered — from server-side validation with Joi and input sanitization against XSS attacks, to graceful error handling with custom error classes and a clean, responsive UI.

Key Features
What it does
🗺️
Interactive Mapbox Maps
Every campground is geocoded and shown on an interactive Mapbox GL map. Click any marker to see the campground preview popup with a direct link.
🔐
User Authentication
Passport.js local strategy with session management. Users can register, log in, and their identity is preserved across pages. Protected routes enforce authorisation.
⭐
Reviews & Ratings
Authenticated users can leave star ratings and written reviews on any campground. Reviews are tied to users — only the author can delete their own review.
📸
Photo Uploads (Cloudinary)
Campground owners can upload multiple images via Multer, which are stored and optimised on Cloudinary's CDN for fast loading globally.
🛡️
Security & Validation
Every form submission is validated server-side with Joi schemas. Mongoose queries are sanitised against NoSQL injection. Helmet.js sets security headers.
🌍
Live Deployment
Deployed on Render.com with MongoDB Atlas cloud database. Environment variables secured, production-ready configuration with proper error handling.

Engineering Challenges
Problems I solved
1
Authorisation vs Authentication
Beyond just logging in, I had to ensure that only the campground owner could edit or delete their listing, and only a review's author could delete their review. This required middleware-based authorisation checks on every relevant route, querying the database to verify ownership before any destructive action.
2
Geocoding & Map Data Pipeline
Integrating Mapbox Geocoding API to convert text location inputs into latitude/longitude coordinates — then storing and displaying them on an interactive Mapbox GL map — required careful async error handling for failed geocoding and fallback logic for ambiguous location strings.
3
Cascading Delete Logic
When a campground is deleted, all associated reviews and Cloudinary images must also be deleted. Implementing this with Mongoose middleware (post delete hooks) and the Cloudinary API ensured no orphaned data remained in the database or CDN after a deletion.
