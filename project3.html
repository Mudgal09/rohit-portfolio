Project Overview
What is this project?

This project is a complete end-to-end machine learning workflow built in Python — from raw, messy data through to trained, evaluated regression models. It's designed to predict house prices based on multiple features like area, bedrooms, location score, and age of the property.

Rather than jumping straight to model training, I emphasised the data science process: understanding the data deeply through EDA, making informed preprocessing decisions, engineering meaningful features, and then systematically comparing model performance using proper train/test splits and cross-validation.

The final model — Random Forest Regression at 95% R² score — was selected based on performance metrics including R², RMSE, and MAE, with Matplotlib/Seaborn visualisations used throughout to surface insights from the data.

ML Pipeline
Step-by-step process
🔍
1. Exploratory Data Analysis (EDA)
Deep dive into the dataset: understanding distributions, identifying outliers, visualising correlations with heatmaps, and spotting patterns between features and the target variable (price).
🧹
2. Data Cleaning
Handling missing values with median/mode imputation, removing duplicate records, correcting data type mismatches, and filtering outliers using IQR-based bounds.
⚙️
3. Feature Engineering
Creating new derived features (price per sq ft, property age categories), encoding categorical variables with label encoding and one-hot encoding, and scaling numerical features for linear models.
🧠
4. Model Training
Training four regression algorithms on the same 80/20 train-test split: Linear Regression, Ridge Regression, Random Forest, and Lasso Regression. Hyperparameters tuned with GridSearchCV.
📊
5. Evaluation & Visualisation
Comparing models using R², RMSE, and MAE metrics. Visualising actual vs predicted plots, residual distributions, and feature importance rankings using Matplotlib and Seaborn.
